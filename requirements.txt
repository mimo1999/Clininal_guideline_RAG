# Consolidated dependencies for the whole pipeline (ingestion, chunking,
# retrieval, generation, evaluation, webapp). Exact versions taken directly
# from `pip freeze` on the machine this project was developed and tested
# against, filtered down to only the packages actually imported anywhere in
# this codebase (grepped, not guessed) -- not the full freeze output, which
# includes ~200 transitive packages irrelevant to reproducing this project
# specifically. See dev_logs.md for the full history of why each
# model/library choice was made.
#
# torch: pinned version below installs a CPU-only build on most platforms.
# If you have an NVIDIA GPU, install the matching CUDA build instead from
# https://pytorch.org/get-started/locally/, e.g.
# `pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cu126`
# -- the retrieval/generation code auto-detects CUDA and falls back to CPU
# cleanly either way (slower, not broken).
#
# Deliberately NOT installing torchaudio (this project never uses audio):
# transformers' audio_utils.py guards its torchaudio import behind
# `if is_torchaudio_available(): import torchaudio`, and that check is a pure
# importlib.util.find_spec() metadata lookup -- it never executes torchaudio's
# own module code. So as long as torchaudio ISN'T installed, the whole import
# is skipped cleanly, no matter what CUDA build torch resolves to. setup.py
# actively uninstalls any pre-existing torchaudio for exactly this reason (see
# dev_logs.md Entry 23) -- some environments (e.g. Google Colab) ship one
# preinstalled, and a *present-but-CUDA-mismatched* torchaudio crashes this
# same import chain with "PyTorch and TorchAudio were compiled with different
# CUDA versions" the moment docling's layout model (which pulls in
# RTDetrImageProcessor, which triggers this chain) loads. An earlier attempt
# to fix this by pinning a matching torchaudio version instead of removing it
# turned out to be both unnecessary and unworkable -- no torchaudio release
# exists for torch==2.13.0 at all (latest available was 2.11.0).
